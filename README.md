# cnsync

All shadcn/ui + ai-elements components, auto-synced from upstream, patched for Base UI compatibility.

## Usage

Copy the `ui/` folder into your project:

```bash
bunx gitpick 1qh/cnsync ui
```

Then update your import alias to match your project’s path (default is `@cnsync/ui`).

## What’s included

- All shadcn/ui components (Base UI variant)
- All ai-elements components
- Typography plugin pre-configured
- Upstream type issues patched
- No radix-ui dependencies

## Auto-sync

Components are synced from upstream on Mon/Thu at 2am UTC via GitHub Actions.
